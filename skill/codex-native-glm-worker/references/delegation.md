# Delegation

- Give each writer an isolated worktree and exclusive files.
- Put the complete task in the exact filesystem envelope.
- Include source/HEAD, scope, invariants, tests, expected report, and stops.
- Good packets usually take 1–6 hours; huge cross-topic research is more reliable when split.
- Keep one slot for root and use fewer than four when boundaries overlap.
- Require focused tests, affected gates, adversarial self-review, and exact remaining uncertainty.
- Root independently reviews every byte and reruns decisive proof.
- Never let the worker self-approve or hide baseline failures.
